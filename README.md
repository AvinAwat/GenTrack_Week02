# GenTrack_Week02

GenTrack is a Flutter application developed as part of the Week 02 university lab.

## Project Description

This project demonstrates Flutter UI development, reusable widgets, expense categories, and basic payment summaries.

## Features

- Payment summary card.
- Recent expenses list.
- Expense categories, including Health.
- Interactive buttons.

## Getting Started

To run this project:

1. Make sure Flutter is installed.
2. Open the project in VS Code.
3. Run the following command:

```bash
flutter pub get
flutter run
